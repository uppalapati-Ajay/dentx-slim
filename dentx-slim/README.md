# DentX-Slim: low-profile intra-oral X-ray sensor

Submission for the DentX Dental X-Ray Sensor Hackathon by [Sai Venkata Ajay Uppalapati](https://github.com/uppalapati-Ajay) ([LinkedIn](https://www.linkedin.com/in/ajay-uppalapati-06865124b)).

**Live interactive simulator:** https://uppalapati-ajay.github.io/dentx-slim/

**Idea:** comfort is limited by sensor thickness and rigid edges, not by the cable. A thin in-mouth head (scintillator, thinner fibre-optic plate, thinned CMOS die, flex) plus a chairside pod whose firmware removes the direct-hit speckle a thinner plate lets through. Design target 4.0 mm vs 5.7 to 7.1 mm for published sensors.

## Contents
- `index.html`: interactive simulator (runs in the browser)
- `DentX_Slim_Technical_Proposal.pdf`: full technical proposal
- `dentx_poc/`: Python simulation, design-space sweep, 3D-printable STL models and figures (see its README)

All simulated results use illustrative parameters and are labelled as such. No X-ray radiation was used.
